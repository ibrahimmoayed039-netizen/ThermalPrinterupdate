# 🖨️ Thermal Printer App - com.mustfa.printer

## خطوات فتح المشروع في Android Studio

### 1️⃣ افتح Android Studio
### 2️⃣ اختر: File → Open
### 3️⃣ اختر مجلد ThermalPrinter
### 4️⃣ انتظر Gradle Sync (دقيقتان تقريباً)
### 5️⃣ اضغط Run ▶️

---

## المكتبات المستخدمة
- `ESCPOS-ThermalPrinter-Android` — طباعة ESC/POS لكل الطابعات
- `ZXing` — توليد الباركود وQR Code
- `Kotlin Coroutines` — عمليات البلوتوث بدون تجميد الواجهة

## الميزات
✅ اتصال بلوتوث بكل الطابعات الحرارية (58mm و 80mm)
✅ طباعة نصوص عربية وإنجليزية وأرقام
✅ محاذاة: يمين / وسط / يسار
✅ تكبير/تصغير الخط (5 أحجام)
✅ غامق وتسطير
✅ طباعة باركود: CODE128, CODE39, EAN13, QR, UPC
✅ طباعة صور من الجهاز
✅ طباعة فاتورة كاملة مع QR
✅ صفحة اختبار
✅ قطع الورق
✅ إعدادات: 58mm / 80mm

## متطلبات
- Android 6.0+ (API 23)
- Android Studio Hedgehog أو أحدث
- JDK 17
